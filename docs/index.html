Bijoy layout Phonetic (Banglish) Zero dependencies

Type Bangla,
without a Bangla keyboard.

Ankan is a floating on-screen keyboard for the web. Drop it into any input and your users get Bijoy typing, phonetic (Avro-style) typing, or both — switchable from one small panel.

Install

No bundler, no build step — plain ES modules served from jsDelivr. Pick the module that matches what you're building; each tab below lists every option it accepts.

One floating panel that lets a user switch between Bijoy key-position typing and phonetic (Banglish) typing. Loads ankanBn.js, ankanEn.js, and ankanShared.js automatically.

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/tanvir-abid/ankan@v1.0.0/ankan.css">

<script type="module">
  import { initAnkanKeyboard } from "https://cdn.jsdelivr.net/gh/tanvir-abid/ankan@v1.0.0/ankan.js";

  initAnkanKeyboard({
    selector: "textarea, input[type=text]",  // string | string[] — default: all text inputs
    defaultMode: "bangla",                   // "bangla" | "phonetic" — default: "bangla"
    closeMode: "permanent",                  // "permanent" | "toggle" — default: "permanent"
    enabled: true,                           // boolean — default: true
    showPanel: true,                         // boolean — default: true
    onPanelToggle: (visible) => {}                // (visible: boolean) => void — default: none
  });
</script>

Quick start

Copy this whole file, save it, open it in a browser. That's the entire setup — no build step, no config.

index.html
<!DOCTYPE html>
<html lang="bn">
<head>
  <meta charset="UTF-8">
  <title>My Bangla App</title>
  <link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/tanvir-abid/ankan@v1.0.0/ankan.css">
</head>
<body>

  <textarea placeholder="Type in English to get Bangla..." rows="6" style="width:100%;font-size:1.1rem;"></textarea>

  <script type="module">
    import { initAnkanKeyboard } from "https://cdn.jsdelivr.net/gh/tanvir-abid/ankan@v1.0.0/ankan.js";
    initAnkanKeyboard({ selector: "textarea" });
  </script>

</body>
</html>

Use cases

Pick the module that matches what you're building.

Combined panel (recommended)

One floating panel, switchable between Bijoy and phonetic from its own header. Best default for comment boxes, forms, chat.

Code
import { initAnkanKeyboard } from "./ankan.js";
initAnkanKeyboard({
  selector: "#message, textarea",
  defaultMode: "phonetic"
});

Bijoy-only keyboard

Just the classic key-position layout, for users who already know Bijoy and don't need phonetic mode cluttering the panel.

Code
import { initBanglaKeyboard } from "./ankanBn.js";
initBanglaKeyboard({ selector: "textarea" });

Phonetic-only, no panel

Silent background conversion as people type romanized Bangla — no floating keyboard, just a tiny optional on/off badge.

Code
import { initPhoneticBangla } from "./ankanEn.js";
initPhoneticBangla({ selector: "textarea", showBadge: false });

Target specific fields

Pass any CSS selector — one field, several, or a shared class across a form.

Code
initAnkanKeyboard({
  selector: ["#comment-box", ".chat-input"]
});

Rich chat boxes (contenteditable)

Works on contenteditable hosts too — Slack-style composers, not just <input>/<textarea>.

Code
<div class="chat-input" contenteditable="true"></div>

initAnkanKeyboard({ selector: ".chat-input" });

Language-switcher UX

Drive the panel from your own UI — open it, close it, or force a mode without waiting for a focus event.

Code
import { showAnkanKeyboard, hideAnkanKeyboard, setAnkanMode } from "./ankan.js";

langSelect.addEventListener("change", () => {
  if (langSelect.value === "bn") {
    setAnkanMode("bangla");
    showAnkanKeyboard();
  } else hideAnkanKeyboard();
});

Convert existing text on demand

Use the phonetic engine directly — no input attachment needed. Good for a "convert" button, or cleaning up text pasted before the listener was attached.

→
আমার সোনার বাংলা
Code
import { convertText } from "./ankanEn.js";
convertText("amar sonar bangla"); // → "আমার সোনার বাংলা"

যুক্তাক্ষর — Conjunct letters

Bangla fuses two or more consonants into a single glyph (a যুক্তাক্ষর) by dropping the vowel between them — ক + ষ becomes ক্ষ, not কষ. Every card below is generated live from the engine's own rule table via getConjunctPatterns(), so it never drifts out of sync with what actually gets typed.

API reference

Three modules, each usable on its own.

setAnkanKeyboardEnabled(bool)Turn the keyboard on/off from outside code.
isAnkanKeyboardEnabled()Current enabled state.
showAnkanKeyboard(targetEl?)Force the panel open on a given (or last-focused) field.
hideAnkanKeyboard()Hide the panel right now.
setAnkanMode(mode)'bangla' or 'phonetic' — switch programmatically.
getAnkanMode()Current mode.
Purpose: the standalone Bijoy-layout keyboard, with no phonetic mode. Use it when your users already know Bijoy key positions and a mode switcher would just be clutter.

setBanglaKeyboardEnabled(bool)Turn on/off from outside code.

hideBanglaKeyboard()Hide the panel.

Purpose: the standalone phonetic (Avro-style) conversion engine. It silently converts romanized Bangla as people type — no floating panel — and can also be called directly to convert any string on demand.

Tips & FAQ

Does this need a bundler?

No — everything is a plain ES module. A single <script type="module"> tag is enough, from a CDN or self-hosted.

What happens on mobile?

On touch devices the native on-screen keyboard is suppressed automatically while a matched field is focused, so people only see Ankan's keys. The panel itself docks to the bottom of the screen below 640px.

Is it safe to call init more than once?

Yes. Re-calling initAnkanKeyboard (or the other init functions) just updates the selector, mode, or enabled state — it won't attach duplicate listeners.

Where does the phonetic rule data come from?

The transliteration pattern table is adapted from Avro Phonetic (OmicronLab / Rifat Nabi), licensed under MPL 1.1. The parsing engine and input-attachment code are original.
